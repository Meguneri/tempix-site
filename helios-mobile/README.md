# Гелиос: Глубокий контур — мобильная версия

Кооперативная браузерная игра. Вся игровая логика уже включена в `index.html`.

## На телефоне, одному (без сервера)

Откройте [index.html](index.html) на GitHub и нажмите **Download raw file**. Откройте скачанный файл в браузере. Если браузер не выполняет JavaScript из локальных HTML-файлов, используйте ссылку для запуска через обычный веб-сервер. Игра не является APK.

## На двух телефонах

Нужен один компьютер с Python 3.10+, работающий как сервер.

1. Скачайте **в одну папку** файлы `index.html`, `server.py` и `START_WINDOWS.bat`. Все три находятся здесь, в ветке `helios-mobile`.
2. На Windows дважды щёлкните `START_WINDOWS.bat`. На macOS/Linux в терминале выполните `python3 server.py`.
3. На обоих телефонах откройте указанный сервером адрес `http://IP:8787`. Для игры в одной квартире телефоны должны быть в домашнем Wi-Fi. Для разных мест нужна настроенная общая VPN, а не просто код комнаты.
4. В меню выберите **«Вдвоём по сети»**. Первый создаёт комнату, второй вводит код, оба выбирают классы, затем первый начинает рейс.

На обоих телефонах нужен браузер, Python только на серверном компьютере. Сервер предназначен для частной LAN/VPN-сети, не публикуйте порт 8787 в открытый интернет.

**Важно:** страница, открытая на стороннем HTTPS-хостинге, может не иметь доступа к локальному WebSocket-серверу по `ws://`. Для сетевой игры открывайте страницу с адреса самого серверного компьютера, а не с CDN.
