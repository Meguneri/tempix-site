# ГЕЛИОС: ЭНТРОПИЯ — для Windows PC

Полный одиночный roguelike + кооператив для двух игроков. В комплекте Windows x64 launcher `HELIOS_ENTROPY_PC.exe`, управляющие BAT-файлы, офлайн HTML.

## Одиночная игра
1. Распакуйте ZIP.
2. Запустите `HELIOS_ENTROPY_PC.exe`. Нужен Microsoft Edge или Google Chrome.
3. Игра откроется в отдельном окне без вкладок. Python, Node.js и интернет **не нужны**.
4. Сохранения хранятся в локальном профиле браузера в `%LOCALAPPDATA%\HeliosEntropyPC\BrowserData`.

## Кооператив
На компьютере ведущего запустите `START_COOP_HOST.bat`. Программа покажет адрес вида `http://192.168.1.10:8787`; второй игрок должен быть в той же LAN/Wi-Fi либо заранее настроенной доверенной VPN-сети (например, ZeroTier).

На другом ПК запустите `JOIN_COOP.bat` и введите IP ведущего; второй игрок также может открыть адрес ведущего в браузере на телефоне. В меню создайте/найдите комнату по шестизначному коду.

**Не открывайте порт 8787 в публичный интернет**; сервер предназначен для частной LAN/VPN-сети. Если Windows Firewall запрашивает доступ, разрешайте только доверенные частные сети.

`START_SERVER_ONLY.bat` запускает сервер без окна игры.

## Управление
WASD — движение; мышь + ЛКМ — прицел и стрельба; Space — рывок; Q — умение класса; E — взаимодействие; R — резонанс; F — перезарядка; Tab — карта; I — улучшения; Esc — пауза. На ПК по умолчанию ручное прицеливание и ручная стрельба. F3 — FPS, F11 — полный экран, колесо мыши — масштаб камеры. Доступны три уровня качества, включая «Ультра».

## Ограничения
Это **desktop-оболочка вокруг 2D Canvas-игры**, а не 3D-движок. Для окна используется установленный Edge или Chrome. EXE не подписан сертификатом и может вызвать SmartScreen. Если запуск exe недоступен, откройте `HELIOS_ENTROPY_OFFLINE.html` через браузер — одиночная игра работает без установок.

Windows-EXE собран кросс-компиляцией; физическое тестирование на Windows пока не проводилось. Логика HTML и WebSocket-сервера проверены в Linux и Chromium.
